# MetaFask

MetaFask is a simple and modern crypto portfolio experience designed for mobile devices.

## What is MetaFask?

MetaFask lets you create a fictional crypto portfolio, choose a cryptocurrency, set your balance, and view its current market price and price history.

Everything is designed to feel like a clean, modern mobile crypto app.

## Features

* 🪙 Choose from thousands of cryptocurrencies
* 💰 Set your own portfolio balance
* 📊 View price charts
* 📈 See current market prices and 24-hour changes
* 🌙 Dark, light, and system themes
* 🌍 English and Turkish language support
* 📱 Designed for iPhone and mobile devices
* 📲 Can be added to your Home Screen as a web app

## Important

MetaFask is **not a real cryptocurrency wallet**.

It does not store, send, receive, or transfer cryptocurrency. The balances shown in the app are fictional and are only used for the portfolio interface.

**Never enter a real private key, seed phrase, or wallet password.**

## Enjoy MetaFask

Explore cryptocurrencies, customize your portfolio, and experience a modern crypto dashboard — without using real funds.
